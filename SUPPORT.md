# Support

## Getting help

- **Documentation:** Start with the `docs/` directory. `docs/INSTALLATION.md` covers setup; `docs/OPERATING_GUIDE.md` covers usage.
- **Skills catalogue:** See `site/skills-catalog.md` for a full index of available skills with descriptions.
- **Examples:** See `examples/` for three end-to-end fictional scenarios.

## Reporting bugs

Open a GitHub issue with:
- The skill or component name
- What you tried to do
- What happened vs. what you expected
- The version or commit hash

## Feature requests

Open a GitHub issue labelled `enhancement`. Include the use case, the problem it solves, and any relevant constraints.

## Security issues

See `SECURITY.md` — do not open public issues for security vulnerabilities.

## Out of scope

This toolkit does not provide:
- Live support or consulting
- Guarantees of sales results
- Legal advice on outreach compliance
- Pre-built CRM integrations (see Release 2 roadmap)
