# Workflows

End-to-end multi-agent sequences. Each workflow defines a trigger, the agents involved, human approval gates, and the expected output.

| Workflow | File | Description |
|---|---|---|
| Account to Meeting | `account-to-meeting.md` | From account selection to booked discovery call |
| Signal to Action | `signal-to-action.md` | From buying signal to approved next action |
| Inbound Lead Triage | `inbound-lead-triage.md` | From inbound lead to routed and qualified opportunity |
| Discovery to Demo | `discovery-to-demo.md` | From confirmed discovery to demo-ready plan |
| Demo to Follow-up | `demo-to-follow-up.md` | From demo notes to structured follow-up package |
| Opportunity Review | `opportunity-review.md` | Weekly opportunity health check |
| Weekly Pipeline Review | `weekly-pipeline-review.md` | Manager-level pipeline summary and risk review |
| Human Approval Gates | `human-approval-gates.md` | Master list of all action classes and their approval tier |
