# Examples

Three fictional end-to-end scenario walkthroughs. All companies and contacts are invented.

| Scenario | Directory | Description |
|---|---|---|
| Account to Meeting | `fictional-account/` | Acme Corp (fictional SaaS vendor) targets Northlight Technologies |
| Outreach Sequence | `fictional-outreach/` | SDR builds a 3-touch outreach sequence for a fictional prospect |
| Pipeline Review | `fictional-pipeline-review/` | Sales Manager runs a weekly pipeline review for a fictional team |

These examples show what each workflow's output looks like in practice. They are designed to be used as test inputs in evaluations.
