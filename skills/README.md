# Skills

Each skill is a named directory containing a `SKILL.md` file. Skills are organised into 7 groups covering the full sales lifecycle.

## Groups

| Group | Directory | Skills |
|---|---|---|
| 1. Find Buyers and Accounts | `01-find-buyers/` | 1–10 |
| 2. Account Intelligence and Signals | `02-account-intelligence/` | 11–20 |
| 3. Run the Pipeline | `03-run-the-pipeline/` | 21–30 |
| 4. Discovery, Demos, and Deal Progression | `04-discovery-and-deals/` | 31–42 |
| 5. Sales Enablement and Management | `05-sales-enablement/` | 43–52 |
| 6. Templates, Trackers, and Revenue Operations | `06-revenue-operations/` | 53–64 |
| 7. Quality, Safety, and Governance | `07-quality-and-safety/` | 65–72 |

## Using a skill

Reference the skill file directly in your agent session:

```
Use skills/01-find-buyers/icp-builder/SKILL.md
```

Or reference it from a workflow that chains multiple skills.
