# Group 6 — Templates, Trackers, and Revenue Operations

Structured templates and RevOps tools for consistent tracking, clean data, and measurable pipeline management.

| Skill | What it does for you |
|---|---|
| [Initial Outreach Template](initial-outreach-template/SKILL.md) | A blank, configurable outreach structure — fill it yourself, or use Skill 25 to generate the content |
| [Meeting Request Template](meeting-request-template/SKILL.md) | A concise, relevant meeting request that respects the recipient's time |
| [Follow-up Sequence Template](follow-up-sequence-template/SKILL.md) | A configurable follow-up cadence with built-in stop conditions |
| [Call Notes Template](call-notes-template/SKILL.md) | A structured call record that works with any CRM |
| [Account Tracker](account-tracker/SKILL.md) | Define how to track accounts — fields, update rules, and ownership |
| [Signal Tracker](signal-tracker/SKILL.md) | Log signals with source, timestamp, confidence, and recommended next action |
| [Pipeline Tracker](pipeline-tracker/SKILL.md) | A consistent view of your opportunities — stage, health, and next steps |
| [Four-Week Rollout Planner](four-week-rollout-planner/SKILL.md) | Plan a four-week adoption programme for the toolkit — with training and review milestones |
| [CRM Field Mapping Planner](crm-field-mapping-planner/SKILL.md) | Map your data model to a target CRM before touching any live data |
| [Data Quality Rules](data-quality-rules/SKILL.md) | Define rules for detecting missing or conflicting CRM fields |
| [Sales Metrics Dictionary](sales-metrics-dictionary/SKILL.md) | Define every metric precisely — numerator, denominator, time window, and source |
| [ROI / Time-Saved Estimator](roi-time-saved-estimator/SKILL.md) | Estimate ROI with visible assumptions — no unsupported claims |
