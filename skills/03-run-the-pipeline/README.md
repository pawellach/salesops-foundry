# Group 3 — Run the Pipeline

Skills for moving accounts from identified to contacted — triage, routing, personalised outreach, and pipeline management.

| Skill | What it does for you |
|---|---|
| [Lead Triage](lead-triage/SKILL.md) | Quickly sort inbound leads — who is worth pursuing, who needs more info, who to pass |
| [Lead Routing Recommendation](lead-routing-recommendation/SKILL.md) | Suggest who should own each lead, with the reasoning documented |
| [Warm-Path Mapping](warm-path-mapping/SKILL.md) | Find who in your network could make a warm introduction to the target account |
| [Personalised Outreach Planner](personalised-outreach-planner/SKILL.md) | Choose the right angle and message for this specific account — not a generic template |
| [First-Touch Draft](first-touch-draft/SKILL.md) | Draft a first-touch message grounded in account research — personalised, not a mass blast |
| [Follow-up Sequence Builder](follow-up-sequence-builder/SKILL.md) | Plan a bounded follow-up cadence with clear stop rules and opt-out respect |
| [Meeting Booking Preparation](meeting-booking-preparation/SKILL.md) | Prepare scheduling options and a clear agenda — never books a meeting without your go-ahead |
| [Pipeline Stage Recommendation](pipeline-stage-recommendation/SKILL.md) | Suggest the right stage for an opportunity based on what you actually know |
| [Opportunity Risk Review](opportunity-risk-review/SKILL.md) | Surface the gaps, blockers, and over-optimism in any active deal |
| [Next-Best-Action Planner](next-best-action-planner/SKILL.md) | Rank what to do next across your pipeline — by value, confidence, and effort |
