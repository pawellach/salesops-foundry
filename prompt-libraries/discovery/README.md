# Discovery Prompt Library

Prompts for discovery question planning and call preparation.

| File | Purpose |
|---|---|
| `discovery-question-generator-prompt.md` | Generate discovery questions for a specific pain area |
| `call-objective-setter-prompt.md` | Define clear objectives for a discovery call |
| `qualification-gap-finder-prompt.md` | Identify what qualification information is still missing |
| `pain-impact-mapper-prompt.md` | Map stated pain to business impact |
