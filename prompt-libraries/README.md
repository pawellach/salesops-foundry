# Prompt Libraries

Reusable prompt fragments for common sales tasks. Each category contains 3–5 prompt templates.

| Category | Directory | Focus |
|---|---|---|
| Research | `research/` | Company research, source evaluation |
| Prospecting | `prospecting/` | ICP, fit scoring, list building |
| Outreach | `outreach/` | First touch, follow-up, subject lines |
| Discovery | `discovery/` | Question frameworks, call objectives |
| Demos | `demos/` | Storyline framing, proof points |
| Negotiation | `negotiation/` | Options framing, trade-off analysis |
| Management | `management/` | Coaching, pipeline review, forecasting |

## Using prompt templates

Each template uses `{{placeholder}}` syntax for variable fields. Replace placeholders with actual values before using.

Templates are fragments — combine them or adapt them to your specific context. They are starting points, not scripts.

All templates require human review before any output is sent externally.
