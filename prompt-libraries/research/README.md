# Research Prompt Library

Prompts for company research and source evaluation.

| File | Purpose |
|---|---|
| `company-overview-prompt.md` | Summarise a company from public sources |
| `source-evaluation-prompt.md` | Assess reliability of a source or claim |
| `news-signal-extraction-prompt.md` | Extract relevant signals from news articles |
| `competitor-landscape-prompt.md` | Map a company's competitive landscape |
| `job-posting-analysis-prompt.md` | Extract insights from job postings |
