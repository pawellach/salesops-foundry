# Prospecting Prompt Library

Prompts for ICP definition, fit scoring, and list building.

| File | Purpose |
|---|---|
| `icp-definition-prompt.md` | Define ICP criteria from a hypothesis |
| `account-fit-scoring-prompt.md` | Score a specific account against ICP criteria |
| `segment-builder-prompt.md` | Define and compare account segments |
| `negative-icp-prompt.md` | Identify disqualification criteria |
