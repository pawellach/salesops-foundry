# Outreach Prompt Library

Prompts for first-touch messages, follow-ups, and subject lines.

| File | Purpose |
|---|---|
| `first-touch-email-prompt.md` | Draft a first-touch cold email |
| `follow-up-email-prompt.md` | Draft a follow-up in an existing thread |
| `subject-line-prompt.md` | Generate subject line options |
| `linkedin-connection-note-prompt.md` | Draft a LinkedIn connection note |
| `break-up-email-prompt.md` | Draft a final break-up email |
